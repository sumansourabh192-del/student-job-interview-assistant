# Student Job & Interview Assistant

A simple web application designed to help students manage job applications and track their placement preparation.

## Features

- Add job applications
- Track company and job role
- Monitor application status
- Delete job applications
- View total application count
- Save data using Local Storage
- DSA Tracker for coding practice
- Data persists after refreshing the browser

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Clone this repository:

   git clone https://github.com/sumansourabh192-del/student-job-interview-assistant.git

2. Open the project folder.

3. Open index.html in your browser.
